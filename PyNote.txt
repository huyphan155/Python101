Day 1:
------------------
Topics:
- JSON ( similar with dict in python )
- serialize / deserialize : json.dumps(data) / json.loads(json_data)
- R/W JSON file

DIFF:
    JSON: true - null
    Python: True - None

SERIALIZE : Python object → JSON
    import json
    data = {
        "level":"ERROR",
        "message":"UART timeout"
    }
    json_data = json.dumps(data) # {"level":"ERROR","message":"UART timeout"}

DESERIALIZE : JSON → Python
    json_data = """
    {
        "level":"ERROR",
        "message":"UART timeout"
    }
    """
    data = json.loads(json_data) # {'level':'ERROR', 'message':'UART timeout' }

Phan biet : json.loads() (Text in json format) vs json.load() ( file object )
